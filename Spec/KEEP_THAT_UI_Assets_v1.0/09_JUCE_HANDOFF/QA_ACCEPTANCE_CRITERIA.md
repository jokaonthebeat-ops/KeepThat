# KEEP THAT! Visual QA Acceptance Criteria

A build is visually approved only if all of the following are true:

- Window opens at exactly **1491 x 1055**.
- Overall look matches the approved mockup with the same panel hierarchy and top-tier premium feel.
- Red/orange and cyan accents are luminous but not cheap or overblown.
- The **KEEP LAST** button is the visual focal point.
- The circular rolling-buffer HUD feels alive and animated.
- Live Input panel, Recovery Tools, Capture Preview, Export panel, Recent Keeps, and Bottom Controls all match the approved arrangement.
- Fonts are clean, modern, and visually close to the reference.
- No plain default JUCE buttons, sliders or combo boxes are visible.
- Waveforms are smooth and anti-aliased.
- Meters animate fluidly.
- Recent keep cards look premium and readable.
- All buttons have hover and pressed states.
- Resizing preserves proportions; no broken layouts.
- High-DPI rendering remains sharp.
